# Void Grid 3v3: Capture The Flag Simulation

A beautiful, hardware-accelerated 3D Capture the Flag simulation set in a glowing virtual world. The game is written in Rust (using Axum for the game engine and WebSockets) and WebGL/Three.js for smooth 64 FPS rendering. 

It is designed to be highly optimized for older laptops by utilizing standard WebGL hardware acceleration in the browser and pure CPU state logic in Rust. It features a pre-game tactics generator and a post-game Systems Audit generated by a local tactical subroutine.

## Features

1. **3D Neon Aesthetics**: Sleek wireframe outlines, particle systems for de-rez explosions, light trails, and neon bloom shaders.
2. **Dynamic AI Roles**:
   - **Stalker**: Fast flag runner with stealth/dash capabilities.
   - **Enforcer**: Slow tank that guards bases with hardlight shields.
   - **Tactician**: Heals teammates with direct nanite links.
3. **Advanced Evasive Physics**: Flag carriers utilize speed-aware, blended lateral-radial evasion. When a defender blockades their path, carriers steer perpendicular to the threat to navigate around them rather than running directly into them.
4. **Grid Tether Buzzsaw**: Nearby allied defenders can establish a linked energy tether. This creates a rotating buzzsaw-like beam that deals high damage to any passing enemies who cross it.
5. **Tactical Simulation Control**:
   - **Pregame Strategy**: The engine analyzes each team and commands them with specific tactics (e.g. `RUSH`, `TURTLE`, `SPLIT`) which dynamically change their AI weights.
   - **Game Master Auditor**: At the end of the match, the local auditor reviews match stats (K/D, flags, healing) and outputs a detailed critique and recommendations for improvement.
6. **Cinematic Cameras**:
   - **Ghost Cam**: Direct mouse look and keyboard navigation to inspect the field.
   - **Action Cam**: Auto-tracks flag carriers, battles, and healers smoothly.
7. **Aging Laptop Optimization**: Easily disable the post-processing Neon Bloom shader in the camera panel for a huge performance boost on low-spec GPUs.

## Controls & Customization

*   **Ghost Flight**: `WASD` to fly horizontally. `Space` to go up. `Left Shift` to go down. Click + drag mouse to look around.
*   **Track Target**: Click "Action Cam" to focus on players, or choose a specific player to track from the HUD dropdown.
*   **Pause Simulation**: Press the Pause button (located under the reboot grid) to halt the game physics and state updates to inspect logs and troubleshoot behaviors.
*   **Reboot Grid**: Restart the match at any time.
*   **Tactics Override**: Force specific tactics (Rush/Turtle/Split) for either team using the pregame overlay buttons.

## Control Panel (Makefile)

A convenient control panel is provided via the `Makefile` to build, run, and monitor the simulation server.

| Command | Description |
|---|---|
| `make build` | Compiles the server in release mode (`cargo build --release`). |
| `make start` | Builds and runs the server in the background, writing logs to `server.log`. |
| `make status` | Checks whether the simulation server is currently running. |
| `make logs` | Tails the server log output in real-time (`tail -f server.log`). |
| `make stop` | Stops the background simulation server cleanly. |
| `make clean` | Removes build artifacts, `server.pid`, and `server.log`. |

## Setup & Running

### 1. Build and Start the Server
To compile and launch the server in the background:
```bash
make start
```
*Alternatively, to run the server in the foreground, run `./run.sh`.*

### 2. View the Grid
Open your web browser to:
[http://localhost:8080/](http://localhost:8080/)
