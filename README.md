# Void Grid 3v3: Capture The Flag Simulation

A beautiful, hardware-accelerated 3D Capture the Flag simulation set in a glowing virtual world. The game is written in Rust (using Axum for the game engine and WebSockets) and WebGL/Three.js for smooth 64 FPS rendering. 

It is designed to be highly optimized for older laptops by utilizing standard WebGL hardware acceleration in the browser and pure CPU state logic in Python. It features a pre-game tactics generator and a post-game Systems Audit generated by a local tactical subroutine.

## Features

1. **3D Neon Aesthetics**: Sleek wireframe outlines, particle systems for de-rez explosions, light trails, and neon bloom shaders.
2. **Dynamic AI Roles**:
   - **Stalker**: Fast flag runner with stealth/dash capabilities.
   - **Enforcer**: Slow tank that guards bases with hardlight shields.
   - **Tactician**: Heals teammates with direct nanite links.
3. **Tactical Simulation Engine**:
   - **Pregame Strategy**: The engine analyzes each team and commands them with specific tactics (e.g. `RUSH`, `TURTLE`, `SPLIT`) which dynamically changes their AI weights. Both teams receive distinct strategies.
   - **Game Master Auditor**: At the end of the match, the local auditor reviews match stats (K/D, flags, healing) and outputs a detailed critique and recommendations for improvement.
4. **Cinematic Cameras**:
   - **Ghost Cam**: Direct mouse look and keyboard navigation to inspect the field.
   - **Action Cam**: Auto-tracks flag carriers, battles, and healers smoothly.
5. **Aging Laptop Optimization Toggle**: Easily disable the post-processing Neon Bloom shader in the camera panel for a huge performance boost on low-spec GPUs.

## Controls

*   **Ghost Flight**: `WASD` to fly horizontally. `Space` to go up. `Left Shift` to go down. Click + drag mouse to look around.
*   **Track Target**: Click "Action Cam" to focus on players, or choose a specific player to track from the HUD dropdown.
*   **Reboot Grid**: Restart the match at any time.
*   **Tactics Override**: Force specific tactics (Rush/Turtle/Split) for either team using the pregame overlay buttons.

## Setup & Running

1. **Python Dependencies**:
   Make sure you have python3 installed on your system. The run script will automatically create a virtual environment and install needed packages (`tornado`, `numpy`, `requests`).

2. **Run the Game**:
   Simply run the start script in your terminal:
   ```bash
   ./run.sh
   ```

3. **View the Grid**:
   Open your browser to:
   [http://localhost:8080/](http://localhost:8080/)
